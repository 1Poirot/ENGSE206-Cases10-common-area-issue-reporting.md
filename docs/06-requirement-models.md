## 4. Use Case Specification

### UC-01 — [แจ้งปัญหาพื้นที่ส่วนกลาง]

| Field | Detail |
|---|---|
| Primary Actor | ผู้แจ้ง |
| Trigger | ผู้แจ้งต้องการแจ้งปัญหาที่เกิดขึ้นในพื้นที่ส่วนกลาง |
| Preconditions | ผู้แจ้งเข้าสู่หน้าการแจ้งปัญหาและสามารถกรอกข้อมูลรายการแจ้งปัญหาได้ |
| Main Success Scenario | 1. ผู้แจ้งกรอกรายละเอียดปัญหา <br> 2. ผู้แจ้งระบุอาคารและตำแหน่งที่เกิดเหตุ <br> 3. ผู้แจ้งเลือกประเภทของปัญหา <br> 4. ผู้แจ้งแนบรูปภาพประกอบอย่างน้อย 1 รูป <br> 5. ผู้แจ้งส่งรายการแจ้งปัญหา <br> 6. ระบบตรวจสอบข้อมูลที่จำเป็น <br> 7. ระบบบันทึกรายการแจ้งปัญหา |
| Alternate / Exception Flows | 1. หากกรอกข้อมูลไม่ครบ ระบบแจ้งเตือนให้กรอกข้อมูลที่จำเป็นให้ครบ <br> 2. หากไม่มีรูปภาพแนบ ระบบแจ้งเตือนให้แนบรูปภาพอย่างน้อย 1 รูป <br> 3. หากบันทึกรายการไม่สำเร็จ ระบบแจ้งข้อผิดพลาดและให้ผู้แจ้งลองใหม่ <br> 4. หากระบบพบว่าผู้แจ้งปัญหาไม่ได้เข้าสู่ระบบ รับบต้องแจ้งเตือนว่าต้องทำการเข้าสู่ระบบก่อน |
| Postconditions | ระบบรายการแจ้งปัญหาถูกบันทึกสำเร็จ |
| Related Requirements | FR-01 |

### UC-02 — [ติดตามสถานะและผลดำเนินการ]

| Field | Detail |
|---|---|
| Primary Actor | ผู้แจ้ง |
| Trigger | ผู้แจ้งต้องการติดตามสถานะการดำเนินงานและรับการแจ้งเตือนเมื่อสถานะเปลี่ยน |
| Preconditions | ผู้แจ้งมีรายการแจ้งปัญหาที่เคยส่งเข้าสู่ระบบ |
| Main Success Scenario | 1. ผู้แจ้งเข้าสู่หน้าติดตามรายการแจ้งปัญหา <br> 2. ระบบแสดงรายการแจ้งปัญหาของผู้แจ้ง <br> 3. ผู้แจ้งเลือกรายการที่ต้องการติดตาม <br> 4. ระบบแสดงสถานะปัจจุบันและผลการดำเนินงานของรายการ |
| Alternate / Exception Flows | [1. หากไม่พบรายการแจ้งปัญหา ระบบแสดงข้อความแจ้งว่าไม่พบรายการ <br> 2. หากไม่สามารถโหลดข้อมูลได้ ระบบแจ้งข้อผิดพลาด] |
| Postconditions | ผู้แจ้งทราบสถานะและความคืบหน้าของรายการแจ้งปัญหา |
| Related Requirements | FR-02 |

### UC-03 — [อัปเดตสถานะ รับการแจ้งเตือน ]

| Field | Detail |
|---|---|
| Primary Actor | เจ้าหน้าที่ |
| Trigger | เจ้าหน้าที่ต้องได้รับการแจ้งเตือนและดูตำแหน่งเหตุเสี่ยงและอัปเดตสถานะ |
| Preconditions | มีรายการแจ้งปัญหาในระบบและเจ้าหน้าที่สามารถเข้าถึงรายการได้ |
| Main Success Scenario | 1. ระบบแจ้งเตือนเมื่อการแจ้งปัญหา <br> 2. เจ้าหน้าที่เข้าสู่ระบบหน้ารายการแจ้งปัญหา <br> 3. ระบบแสดงรายการแจ้งเตือนการแจ้งปัญหา <br> 4. เจ้าหน้าที่ตรวจสอบรายละเอียดของรายการแจ้งปัญหา <br> 5. เจ้าหน้าที่เปลี่ยนสถานะของปัญหา <br> 6. ระบบยืนยันการเปลี่ยนสถานะ <br> |
| Alternate / Exception Flows | 1.  หากพบรายการแจ้งปัญหาซ้ำ เจ้าหน้าที่เลือกดำเนินการลบรายการใดรายการหนึ่งและแจ้งเหตุผล <br> 2. หากระบบมีแจ้งเตือนปัญหาพร้อมกัน ระบบต้องแยกการแจ้งเตือนออกเป็นรายรายการ |
| Postconditions | ระบบอัปเดตสถานะได้ |
| Related Requirements | FR-04 |

### UC-04 — [ค้นหาและตรวจสอบประวัติการดำเนินงานย้อนหลัง]

| Field | Detail |
|---|---|
| Primary Actor | [ผู้ดูแลระบบ] |
| Trigger | ผู้ดูแลระบบต้องการค้นหาและตรวจสอบประวัติการดำเนินงานย้อนหลัง |
| Preconditions | ผู้ดูแลระบบต้องการค้นหาและตรวจสอบประวัติการดำเนินงานย้อนหลัง |
| Main Success Scenario | 1. ผู้ดูแลระบบเข้าสู่หน้ารายการแจ้งปัญหา <br> 2. ผู้ดูแลระบบค้นหารายการตามข้อมูลที่ต้องการ <br> 3. ผู้ดูแลระบบตรวจสอบประวัติย้อนหลัก <br> 5. ระบบแสดงรายละเอียดของรายการ เช่น รายละเอียดปัญหา รูปภาพ อาคาร ตำแหน่ง และประเภทปัญหา |
| Alternate / Exception Flows | 1. หากไม่พบรายการที่ตรงกับเงื่อนไข ระบบแจ้งว่าไม่พบข้อมูล |
| Postconditions | ผู้ดูแลระบบสามารถดูประวัติย้อนหลังได้ |
| Related Requirements | FR-05 |
