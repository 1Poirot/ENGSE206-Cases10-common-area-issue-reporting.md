## 2. Acceptance Criteria

### AC-01 — การส่งรายงานแจ้งปัญหาครบถ้วนในขั้นตอนเดียว
- **Given** ผู้ใช้งานเข้าสู่หน้าแบบฟอร์มแจ้งปัญหาพื้นที่ส่วนกลาง
- **When** ผู้ใช้งานแนบรูปภาพ ระบุอาคาร ตำแหน่ง และเลือกประเภทของปัญหาครบถ้วน แล้วกดยืนยันส่งข้อมูล
- **Then** ระบบบันทึกข้อมูลคำร้องสำเร็จ สร้างรหัสคำร้อง และแสดงข้อความยืนยันการส่งรายการ

### AC-02 — การติดตามสถานะและการแจ้งเตือนเมื่อสถานะเปลี่ยน
- **Given** มีรายการแจ้งปัญหาที่บันทึกอยู่ในระบบ
- **When** เจ้าหน้าที่ทำการเปลี่ยนสถานะของรายการ เช่น เป็น "กำลังดำเนินการ" หรือ "เสร็จสิ้น"
- **Then** ผู้แจ้งได้รับการแจ้งเตือนความคืบหน้า และหน้าติดตามสถานะแสดงสถานะใหม่ที่ตรงกันทันที

### AC-03 — การค้นหาและกรองรายการแจ้งปัญหา
- **Given** เจ้าหน้าที่เปิดหน้ารายการแจ้งปัญหาทั้งหมด
- **When** เจ้าหน้าที่เลือกเงื่อนไขตัวกรอง เช่น อาคาร ประเภทปัญหา หรือระดับความเร่งด่วน
- **Then** ระบบแสดงผลเฉพาะรายการแจ้งปัญหาที่ตรงตามเงื่อนไขที่กำหนดได้อย่างถูกต้อง

### AC-04 — การอัปเดตสถานะและบันทึกผลการดำเนินงาน
- **Given** เจ้าหน้าที่เปิดดูรายละเอียดคำร้องที่ได้รับมอบหมาย
- **When** เจ้าหน้าที่บันทึกผลการปฏิบัติงานและเปลี่ยนสถานะเป็น "เสร็จสิ้น"
- **Then** ระบบบันทึกผลการทำงาน อัปเดตสถานะของรายการ และบันทึกประวัติการเปลี่ยนแปลงลง Audit Log

### AC-05 — การตรวจจับและรวมรายการแจ้งปัญหาที่ซ้ำซ้อน
- **Given** มีรายการแจ้งปัญหาใหม่ที่มีตำแหน่งและช่วงเวลาใกล้เคียงกับรายการที่มีอยู่เดิม
- **When** เจ้าหน้าที่เลือกดำเนินการรวมรายการที่ซ้ำซ้อนเข้าด้วยกัน
- **Then** ระบบรวมรายการเป็นเคสเดียวกัน โดยยังคงจัดเก็บข้อมูล รายละเอียด และรายชื่อของผู้แจ้งแต่ละรายไว้อย่างครบถ้วน

### AC-06 — การมอบหมายและโอนย้ายงาน
- **Given** รายการแจ้งปัญหายังไม่มีผู้รับผิดชอบ หรือต้องการส่งต่อให้หน่วยงานอื่น
- **When** เจ้าหน้าที่เลือกมอบหมายงานหรือโอนย้ายให้เจ้าหน้าที่/หน่วยงานที่รับผิดชอบใหม่
- **Then** ระบบปรับปรุงชื่อผู้รับผิดชอบปัจจุบัน และบันทึกประวัติการมอบหมายงานลงในระบบ

### AC-07 — การแจ้งเตือนเหตุเร่งด่วนด้านความปลอดภัย
- **Given** ผู้ใช้งานส่งรายงานแจ้งปัญหาที่มีความเสี่ยงด้านความปลอดภัย
- **When** ระบบตรวจพบประเภทปัญหาที่ถูกจัดอยู่ในกลุ่มความเสี่ยงด้านความปลอดภัย
- **Then** ระบบจำแนกระดับความเร่งด่วนสูงสุด แสดงตำแหน่งที่เกิดเหตุ และส่งการแจ้งเตือนไปยังผู้ดูแลความปลอดภัยทันที

### AC-08 — การสร้างรายงานสรุปภาพรวม
- **Given** ผู้ดูแลระบบเข้าสู่หน้าการสร้างรายงาน
- **When** กำหนดช่วงเวลาและเงื่อนไขที่ต้องการวิเคราะห์ข้อมูล
- **Then** ระบบประมวลผลและแสดงรายงานสรุปสถิติการแจ้งปัญหาที่ตรงกับข้อมูลจริงในระบบ

### AC-09 — การตรวจสอบประวัติย้อนหลัง (Audit Log)
- **Given** ผู้ดูแลระบบเข้าสู่หน้าตรวจสอบ Audit Log
- **When** ทำการค้นหาประวัติการดำเนินงานของรายการแจ้งปัญหา
- **Then** ระบบแสดงรายชื่อผู้ดำเนินการ วันเวลา และรายละเอียดการเปลี่ยนแปลง โดยไม่มีตัวเลือกให้แก้ไขหรือลบข้อมูลประวัติ

### AC-10 — การควบคุมสิทธิ์การเข้าถึงตามบทบาท (RBAC)
- **Given** ผู้ใช้งานลงชื่อเข้าใช้งานระบบด้วยบทบาทใดบทบาทหนึ่ง
- **When** พยายามเข้าถึงข้อมูลหรือเรียกใช้งานฟังก์ชันต่างๆ ภายในระบบ
- **Then** ระบบอนุญาตให้เข้าถึงได้เฉพาะฟังก์ชันและข้อมูลที่ได้รับสิทธิ์ตามบทบาทนั้นๆ เท่านั้น
